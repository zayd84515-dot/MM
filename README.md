# متجر عافية

متجر ملابس عربي متجاوب بواجهة HTML/CSS/JavaScript، وخادم Node.js مدمج دون حزم خارجية.

## التشغيل

يتطلب Node.js 22.5 أو أحدث لاستخدام SQLite المدمج في Node.js. حدّث كلمة مرور الإدارة في `.env` إلى كلمة قوية وفريدة، واستبدل مفتاح Gemini قبل النشر. شغّل من PowerShell:

```powershell
npm.cmd start
```

بعدها افتح `http://localhost:3000` للمتجر أو `http://localhost:3000/admin.html` للإدارة. يمكن حذف سطر GEMINI_API_KEY إن لم تكن تريد تفعيل المساعد الذكي. عند عدم إعداد `ADMIN_PASSWORD` يظل المتجر متاحًا لكن تسجيل دخول لوحة الإدارة معطّل.

شغّل نسخة واحدة فقط من الخادم. إذا كان المتجر يعمل بالفعل، لا تشغّل `npm.cmd start` مرة أخرى؛ لإعادة التشغيل اضغط `Ctrl+C` في نافذة الخادم الأول ثم شغّل الأمر مرة واحدة.

غيّر المنفذ بتعديل متغير البيئة `PORT` في `.env`. يمكن نقل قاعدة البيانات والصور إلى مجلد آخر عبر `DATA_DIR`. ملف `.env` محلي ومستثنى من Git؛ لا تنسخه إلى ملفات الواجهة.

## المزايا

- عرض المنتجات والتصفية والبحث وسلة محفوظة في المتصفح.
- إتمام الطلب بالدفع عند الاستلام وحفظه على الخادم مع تفاصيل العميل.
- لوحة إدارة محمية بكلمة مرور لإضافة المنتجات وتعديلها وحذفها، ومتابعة الطلبات وتغيير حالتها.
- مساعد دردشة اختياري يتصل بخدمة Gemini من الخادم فقط. النموذج الافتراضي `gemini-2.5-flash` ويمكن تغييره في `GEMINI_MODEL`. إذا لم يكن النموذج متاحًا للمفتاح، يحاول الخادم تلقائيًا اختيار نموذج Flash آخر يدعم `generateContent`. إذا لم يستطع عرض النماذج، تأكد أن المفتاح من Google AI Studio وأن Gemini API مفعّلة للمشروع، ثم حدّث الإعدادات وأعد تشغيل `npm.cmd start`.
- تُحفظ بيانات المنتجات والطلبات في قاعدة SQLite داخل `data/store.sqlite` على القرص. خذ نسخة احتياطية منها؛ قاعدة البيانات المحلية مناسبة لخادم واحد، وليست إعدادًا متعدد الخوادم أو قاعدة بيانات مُدارة.
- ارفع صور المنتجات من الجهاز بصيغ JPG أو PNG أو WebP (حتى 5 ميجابايت للصورة)، وتُحفظ في `data/uploads`.

## الأمان والنشر

- لا تضع مفاتيح API أو كلمة مرور الإدارة في ملفات `public` أو في Git. مررها كمتغيرات بيئة للخادم.
- إذا سبق مشاركة مفتاح API، ألغِه وأنشئ مفتاحًا بديلًا قبل استخدامه.
- استخدم HTTPS عند النشر. بيانات الزبائن والطلبات محفوظة في قاعدة SQLite محلية، لذا إعداد قاعدة بيانات مُدارة ونسخ احتياطية مناسبة مطلوب قبل الاستخدام الإنتاجي واسع النطاق.
- ملفات الصور المرفوعة موجودة في `data/uploads`؛ احتفظ بنسخة منها مع قاعدة البيانات عند النسخ الاحتياطي.
